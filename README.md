# PyDiv – Linear Algebra Solver

A simple GUI-based **Linear Algebra Solver** built using Python, Tkinter and NumPy.

## Features

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Scalar Multiplication
* Matrix Transpose
* Determinant
* Inverse
* Trace
* Eigenvalues & Eigenvectors
* Matrix Power
* Solve `Ax = B`
* Matrix Rank
* Matrix Properties Checker
* Input validation and error messages

## Technologies Used

* Python
* Tkinter
* NumPy

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/PyDiv-Linear-Algebra-Solver.git
```

### 2. Open the Project

```bash
cd PyDiv-Linear-Algebra-Solver
```

### 3. Install NumPy

```bash
pip install -r requirements.txt
```

### 4. Run the Project

```bash
python main.py
```

## How to Use

1. Enter Matrix A row-wise.
2. Enter Matrix B when required.
3. Enter scalar/power value if required.
4. Select the required operation.
5. View the result in the output section.

### Example Input

```text
1 2 3
4 5 6
7 8 9
```
